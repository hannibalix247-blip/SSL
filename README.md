# 🏃‍♂️ 소담초등학교 학생스포츠클럽 대회 선수 인솔 관리 시스템

세종시 소담초등학교 교사들이 학생스포츠클럽(족구, 배구, 농구, 플라잉디스크, 배드민턴, 티볼) 대회 일정 및 선수 인솔 현황을 한눈에 파악하고, 실시간으로 공유/수정/영구 보존할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **귀여운 종목별 테마 및 배지**
   - ⚽ **족구**: 발과 머리로 네트를 넘기는 전통 스포츠
   - 🏐 **배구**: 스파이크와 토스로 팀워크를 다지는 경기
   - 🏀 **농구**: 골밑을 향해 달리는 열정의 코트
   - 🥏 **플라잉디스크**: 하늘을 가르는 원반 얼티미트 & 윷놀이
   - 🏸 **배드민턴**: 날렵한 스매시와 빠른 랠리
   - ⚾ **티볼**: 홈런을 향해 힘차게 배트를 휘두르는 경기

2. **한눈에 파악하는 인솔 대시보드**
   - **D-Day 카운트다운 & 최우선 임박 경기 배너**
   - **출전 요약 통계**: 총 대회 수, 출전 학생 총원, 인솔 및 지도교사 수, 예정된 경기 수
   - **3가지 맞춤 뷰 모드**:
     - 📋 **카드 뷰**: 종목 뱃지, 일시/장소, 집결지, 인솔교사 연락처(원클릭 전화걸기), 선수 명단 태그
     - 📅 **타임라인 뷰**: 날짜순 일정 흐름을 캘린더 타임라인으로 확인
     - 📊 **테이블 뷰**: 엑셀 스타일로 전체 목록 비교 및 관리

3. **실시간 공유 & 영구 데이터 보존**
   - **Firebase Cloud Firestore 실시간 연동**: 링크만 있으면 여러 교사가 동시 접속하여 추가/수정 사항이 화면에 즉시 실시간 동기화
   - **오프라인/로컬 영구 저장**: 브라우저 로컬 스토리지에 자동 저장되어 새로고침하거나 브라우저를 닫아도 데이터 보존
   - **데이터 백업 및 복원**: 전체 데이터를 JSON 파일로 다운로드 및 업로드 지원

4. **교사용 현장 편의 기능**
   - **인솔 계획서 원클릭 인쇄/PDF 저장**: 학교 결재 및 현장 지참용 A4 규격 서식 출력
   - **엑셀(CSV) 다운로드**: 전체 인솔 현황표를 엑셀 파일로 즉시 내보내기
   - **모바일 메신저 공유 텍스트 복사**: 학부모 및 교사용 안내문 자동 생성 및 복사
   - **선수 일괄 등록 기능**: 한글/엑셀 명단을 복사해 붙여넣으면 한 번에 등록

## 🚀 로컬 실행 방법

```bash
# 의존성 패키지 설치
npm install

# 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하시면 즉시 사용하실 수 있습니다.

## ☁️ 무료 웹 배포 방법 (GitHub Pages, Vercel, Netlify)

1. **Vercel 원클릭 배포**:
   - GitHub 저장소에 푸시 후 [Vercel](https://vercel.com)에서 해당 저장소를 임포트하면 1분 만에 고유 웹 링크가 생성됩니다.
2. **Firebase 실시간 DB 연결**:
   - 웹앱 상단의 **[로컬 저장 모드 (공유 설정)]** 버튼을 눌러 Firebase 콘솔에서 무료 생성한 프로젝트 설정값을 붙여넣으면 모든 교사가 실시간으로 동기화됩니다.
